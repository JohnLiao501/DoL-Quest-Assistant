# 欲都孤儿任务助手

一款面向《Degrees of Lewdity / 欲都孤儿》中文玩家的任务核验工具。它会读取当前游戏状态或本地导出的存档，结合存档变量、游戏逻辑与中文 Wiki 攻略，整理未完成、尚未解锁、需要确认和已完成的任务。

项目提供两种使用方式：

- **游戏内 Mod（推荐）**：直接读取正在游玩的当前存档，在游戏右侧显示“任务”按钮。
- **Windows 独立版**：把 `.save` 文件拖入本地页面分析，无需安装 Mod。

> 本项目不是游戏官方组件，不包含游戏本体、用户存档或 Wiki 页面缓存。任务判定和攻略内容可能落后于游戏更新，请以当前版本的游戏逻辑为准。

## 游戏内 Mod

### 兼容范围

| 项目 | 当前兼容版本 |
| --- | --- |
| 游戏 | 0.5.11.9 |
| ModLoader | 2.31.2 及以上 |
| Mod 原型 | 0.1.2 |

### 安装

1. 从 GitHub Releases 下载最新的 `DoLQuestAssistant-v*.mod.zip`。
2. 打开游戏左下角的“Mod管理器”（电脑可按 `Alt+M`）。
3. 进入“添加/移除Mod”，选择下载的 `.mod.zip`。
4. 点击“添加旁加载Mod”，出现成功提示后刷新游戏。
5. 读取或创建存档后，点击游戏右侧的“任务”按钮。

游戏首页尚未读取存档时，助手只会提示“尚未读取存档”，不会把角色创建的临时变量当作任务进度。

## Windows 独立版

### 运行条件

- Windows 10 或 Windows 11
- Node.js 22（首次使用需要联网安装依赖）

### 使用

1. 下载并解压源码，或克隆本仓库。
2. 双击 `00_启动任务助手.cmd`。
3. 首次启动会安装依赖并构建页面，之后浏览器会自动打开。
4. 将 `.save` 文件拖入页面，或点击“选择存档”。
5. 按分类查看结果，也可以导出 Markdown 清单。

启动窗口会显示当前进度。浏览器页面实际连接成功后，窗口短暂停留并自动关闭；启动失败时窗口会保留，方便查看原因。关闭最后一个助手页面后，本地服务会自动结束。完整启动记录保存在本机的 `logs/startup.log`。

如果希望静默启动，可以双击 `start-helper.vbs`；静默启动失败时会显示错误提示。

## 数据与联网说明

- 独立版存档只在浏览器本机解析，不会上传到助手服务器或 Wiki。
- Mod 直接读取游戏当前状态，不会发送完整存档。
- 联网请求仅用于匿名查询欲都孤儿中文 Wiki 的公开攻略。
- Wiki 实时连接失败时，会使用最近一次成功同步的本地缓存，并在界面中明确标注。
- 人工确认结果只写入助手专属字段，不修改游戏原任务变量。

## 判定边界

- 任务规则以存档变量和当前版本游戏逻辑为主，Wiki 用于补充攻略说明与来源链接。
- Wiki 可能落后于游戏版本，冲突时以游戏实际状态为准。
- 少数事件没有永久完成标记，会归入“需要确认”。
- 年度任务变量可能在跨年时清除，因此不会被武断判定为“从未完成”。

## 本地开发

```powershell
npm ci
npm test
npm run dev
```

独立版生产构建：

```powershell
npm run build
```

Mod 开发、构建与打包：

```powershell
npm run dev:mod
npm run build:mod
npm run package:mod
```

打包脚本会从 `mod/boot.json` 读取版本号，并在本机 `release/` 目录生成 `.mod.zip`。构建目录、发布包、日志、缓存、依赖和存档均已排除在 Git 提交之外。

## 项目结构

```text
src/        独立版界面与任务判定核心
mod/        游戏内 Mod 入口、界面与运行时桥接
scripts/    Mod 打包脚本
test/       自动化测试
```
