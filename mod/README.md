# 欲都孤儿任务助手 Mod v0.1.8

这是游戏内原型版。加载后，游戏右侧会出现“任务”悬浮按钮；点击即可读取当前存档并显示任务状态。

## 当前功能

- 直接读取正在游玩的存档，不需要另行导出 `.save` 文件。
- 复用独立版的任务判定规则，显示未完成、尚未解锁、需要确认等状态。
- 每次启动游戏后首次打开任务面板会匿名刷新欲都孤儿中文攻略站；连接失败时使用浏览器本地缓存，本次会话后续打开不重复自动请求。
- 人工确认结果写入当前存档的专属字段，不改动原任务变量。
- 可导出 Markdown 文本清单。

## 安装

1. 打开游戏左下角的“Mod管理器”（电脑可按 `Alt+M`）。
2. 进入“添加/移除Mod”，选择本 `.mod.zip` 文件。
3. 点击“添加旁加载Mod”，出现成功提示后刷新游戏。

## 兼容范围

- 游戏版本：0.5.11.9
- ModLoader：2.31.2 及以上

这是第一版原型。建议先在备份存档上试用；若游戏或任务规则更新，请等待对应版本的助手更新。
